1. Trên kaggle tạo dataset rồi add file zip này vào, cách tạo zip dưới đây, sau đó tự đặt tên cho dataset.
2. Đăng ký / Đăng nhập Hugging Face, sau đó tạo 1 Access Token có type là Write, lưu lại vào notepad.
3. Chạy file notebook, vào phần add-ons -> secret add token ở trên vào, đặt tên là HF_TOKEN (hoặc tùy chọn).
4. Ở góc phải phần Save Version, chọn Save and Commit, advance options chọn chạy bằng T4,
mục đích là để chạy tự động.
